# পেটুক বাঘ (Petuk Baagh)

A Bengali 3D browser game: a hungry tiger stalks, pounces and jumps its way from the Sundarbans into villages and towns.

**Play:** https://mcodexvb.github.io/petuk-baagh/

Runs in any modern browser on phone or computer. Single-file game (`index.html`) built with three.js.
